# 安全 · Security

发现安全问题（例如可选后端 `server/` 的鉴权、同步或附件接口，或隐私扫描漏掉了某类敏感信息），请不要公开提 issue，
而是在仓库的 **Security → Report a vulnerability** 私下报告。我们会尽快确认并在修复后致谢。

If you find a security problem (for example in the optional backend's authentication, sync or attachment
endpoints, or a kind of secret the privacy scan misses), please do not open a public issue. Report it privately
via **Security → Report a vulnerability** in this repository. We will confirm as soon as we can and credit you
once it is fixed.
